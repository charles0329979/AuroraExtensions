# 开发签名到正式签名的隔离迁移验收（2026-09-18）

## 测试边界

- 使用独立 Android 16 / API 36 x86_64 模拟器 `emulator-5556` 和应用调试包 `app.aurora.reader.dev`，未操作用户平板。
- 旧仓库：`https://raw.githubusercontent.com/charles0329979/AuroraExtensions/main/repo/repo.json`；新仓库：`https://raw.githubusercontent.com/charles0329979/AuroraExtensions/feature/scripted-source-s1/repo/repo.json`。新仓库仍是功能分支，并非公开稳定版。
- 只迁移 `Kuaikanmanhua`（快看漫画）一个 APK，不代表全部 41 个插件。

## 操作及观察

1. 在应用内导入旧仓库并安装旧版快看漫画。系统记录包名 `eu.kanade.tachiyomi.extension.zh.kuaikanmanhua`、版本号 `1.4.13`、版本代码 `104013`。旧仓库目录的签名指纹为 `bdad9277107238147f0650197a40acde8063a6c5889af3cfd4837e1091242770`。
2. 用旧插件打开热门列表和《怦然心动》详情，取得 254 章目录，并将作品加入书架。
3. 在应用内移除旧仓库。旧插件虽然仍安装，但“书源”列表不再显示快看漫画；《怦然心动》仍留在书架。随后通过插件信息页卸载旧 APK，未清除应用数据。
4. 导入新功能分支仓库，重新启用“中文（简体中文）”语言筛选，再从应用内安装正式签名快看漫画。系统记录同一包名和版本号，但版本代码为 `13`；新仓库目录的签名指纹为 `ab89095763a830aedbf82018c5179b9be53fa999a11e8cd69f563e0b5486d7e0`。没有出现“未信任”提示。
5. 从原有书架项目重新打开《怦然心动》：仍显示“已在书架”、原详情及 254 章目录。打开一话，阅读器取得 31 页并显示第 1 页图片。
6. 两个仓库的快看漫画书源 ID 均为 `8099870292642776005`，包名和书源 ID 未变；这解释了原书架项目无需重新收藏即可接回新插件。
7. 强制结束并重新启动应用后，《怦然心动》仍在书架，快看漫画仍出现在“书源”列表，未重新变为“未信任”。

## 结论与限制

这条“移除旧仓库 → 卸载旧签名插件 → 添加新仓库 → 安装正式签名插件 → 恢复原书架阅读”链路在隔离模拟器通过。旧 APK 不能直接覆盖升级：签名不同，且旧版本代码 `104013` 高于新版 `13`。用户版需要明确迁移提示和备份指引，不能自动卸载用户插件。

这部作品在迁移前后均显示“缺少 1 章”，不能把 254 章目录视为所有章节完整性的证明。

尚未验证：其余插件的迁移、离线章节在插件重装后的读取、应用数据备份恢复、不同 Android 版本和真实用户设备。此结果不授权合并或发布 `main`。
