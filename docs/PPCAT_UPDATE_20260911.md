# 皮皮喵 0.9.0 书源更新审计（2026-09-11）

## 结论

连接设备中的皮皮喵已更新到 0.9.0（versionCode 1143）。本次从“站点来源”页重新提取 438 条来源，对全部入口完成两轮网络检测；新增、换址以及上次未能判定的来源在皮皮喵内重新做了分类结果检测，其余同名同址来源沿用 8 月 28 日的列表级结果。

- 旧清单：440 条；新清单：438 条。
- 精确新增：44 条；精确移除：46 条。
- 其中同名换址 2 条：漫画大全、猕猴桃漫画。
- 真机列表级可用：122 条；部分可用：196 条；失效：118 条；需要登录：2 条。
- 可用漫画源 110 条，其中 Aurora 已有实现 35 条，尚待实现 75 条。

“可用”只表示皮皮喵的分类或搜索能返回漫画条目。进入 Aurora 正式仓库前，仍必须通过目录、搜索、详情、章节、图片列表、单图下载的完整链路。

## 可利用的新途径

1. 优先分析“同一站点的网页入口 + APP/API 入口”。漫画台、漫客栈、拷贝漫画已经给出成对路径，可以做主备路由和故障切换。
2. 对“普通网络探测受限、皮皮喵内仍可列出漫画”的来源，重点定位必要请求头、Cookie 初始化或公开 JSON 接口，而不是直接照搬加密仓库。
3. 对频繁换域名来源建立镜像发现层。候选插件只保存经过验证的域名集合，并通过健康检测选择当前可用入口。
4. 皮皮喵订阅仓库 `hgz-x/ppcat_store` 本次只有一个新增的 WEBTOON 繁体中文测试规则；Aurora 已有 Webtoons.com 插件，因此无需重复接入。该测试规则也明确提示搜索和图片可能依赖 JavaScript/Cookie，不能据此视为完整健康源。
