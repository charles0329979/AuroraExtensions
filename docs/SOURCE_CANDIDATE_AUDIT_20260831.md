# 酷漫星与零界绘候选书源审计

审计日期：2026-08-31。

结论：两者的规则结构已经定位，但目前都不满足 Aurora 的完整健康源门槛，因此没有生成 APK，也没有写入公开仓库索引。它们被登记为候选隔离项，防止“能显示目录”被误发布成“能完整阅读”。

## 健康门槛

一个源只有在目录、搜索、详情、章节、图片列表和实际图片下载全部通过，并且不需要绕过登录、付费、广告解锁或其他访问控制时，才允许进入 `repo/index.min.json`。

## 酷漫星

- 样本：Android 4.3.01，包名 `com.onekmx.xsmddha`。
- 已验证：榜单、详情和完整章节列表能够返回真实数据。
- 未通过：阅读接口在没有原 App 的奖励广告解锁状态时，只返回占位图。
- 决策：标记为 `blocked_access_control`。不模拟广告完成状态，不发布只有目录而不能阅读的插件。

## 零界绘（用户输入“零绘界”）

- 样本：Android 2.0.1，包名 `com.ljh.lingjiehui`。
- 当前配置：公开配置文件给出动态 API、静态数据、图片和缓存域名。
- 数据结构：列表是静态 JSON；详情和章节按漫画 ID 分桶打包，结构本身适合高效缓存。
- 未通过：静态漫画 CDN 返回 HTTP 403，请求依赖原 App 中受保护原生代码生成的 `ed` 授权值。
- 决策：标记为 `blocked_native_authorization`。不复制壳或原生授权模块到书源插件。

## 重新启用条件

满足以下任一条件后可重新审计：

1. 服务方提供公开、稳定、允许第三方客户端使用的 API；
2. 正文图片链恢复匿名读取；
3. 用户提供该源的公开网站入口，且网站阅读链与 App 内广告/授权链相互独立。

重新审计仍需在连接设备上完整走通“搜索 → 详情 → 章节 → 图片列表 → 实际图片解码”，通过后才能建立扩展模块并加入仓库索引。
